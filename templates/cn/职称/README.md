# 职称 / 资质 / 晋升申报

> 可选轨道：用于职称、执业资质、专业认证、内部晋升或破格申报。

建议目录：

```
.
├── 00-原始材料/          # 官方规则、用户原文、评审通知
├── 01-个人匹配评估/      # 条件拆解、差距分析
├── 02-证据矩阵/          # 条件 → 证据 → 缺口 → 风险措辞
├── 03-申报文稿/          # 个人总结、业绩材料、项目说明
└── 04-行动方案/          # 补证计划、时间表、预审记录
```

原则：

- 先拆规则，再写材料。
- 对每条承重声明标注证据来源。
- 区分个人主导、团队成果和单位/公司口径。
- 无法证明的内容标为待确认或改成稳妥措辞。
