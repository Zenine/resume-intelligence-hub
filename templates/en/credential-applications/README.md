# Credential / Promotion Dossiers

> Optional track for professional titles, licenses, board certifications, internal promotion packets, and exceptional-track applications.

Suggested structure:

```
.
├── 00-source-rules/       # Official rulebooks, notices, raw user notes
├── 01-fit-assessment/     # Eligibility decomposition and gap analysis
├── 02-evidence-matrix/    # Requirement -> evidence -> gap -> wording risk
├── 03-drafts/             # Personal statements, achievement sheets, project narratives
└── 04-action-plan/        # Missing-proof plan, timeline, pre-review notes
```

Principles:

- Decompose the rules before writing the dossier.
- Attach evidence to every load-bearing claim.
- Separate personal ownership, team outcomes, and company/institution metrics.
- Mark unverifiable content as pending or rewrite it conservatively.
